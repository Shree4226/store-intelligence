# Store Intelligence

## Overview

Store Intelligence is a comprehensive system for detecting and analyzing store-related data patterns.

## Getting Started

### Prerequisites
- Python 3.8+
- Docker and Docker Compose

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run using Docker Compose:
   ```bash
   docker-compose up
   ```

## Project Structure

- `detection/` - Detection algorithms and models
- `api/` - REST API and backend services
- `dashboard/` - Frontend dashboard
- `tests/` - Test suites
- `data/` - Data storage and samples
- `docs/` - Documentation
